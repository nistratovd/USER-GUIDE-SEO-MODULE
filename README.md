# SEO по шаблонам. Инструкция для контент-менеджера

Модуль управляет заголовками, описаниями и SEO-текстами страниц. Он подставляет данные каталога при открытии страницы с фильтром. Например, из одного шаблона можно получить заголовки «Детская обувь Pablosky» и «Детская обувь Geox» для двух разных значений бренда. Для отдельного адреса можно задать собственный текст.

Откройте административную часть Битрикс и перейдите в **Сервисы → SEO по шаблонам**. Для изменения настроек нужны права записи. Если меню не видно или доступны только просмотр и проверка, обратитесь к администратору.

## Как выбрать нужный раздел

| Задача | Куда перейти |
|---|---|
| Подготовить один комплект метаданных для повторного использования | **Наборы шаблонов** |
| Применить комплект к страницам с определённым брендом, цветом или сочетанием условий | **Правила применения** |
| Изменить метаданные одного известного адреса | **Индивидуальные страницы** |
| Подключить каталог или назначить ему базовые метаданные | **Профили каталога** |
| Собрать адрес по разделу и значениям фильтра | **Страница по фильтру** |
| Узнать, какие значения получит готовый адрес и откуда | **Проверка URL** |
| Посмотреть автора правки и вернуть прежние значения | **История изменений** |
| Проверить и применить правки сразу к нескольким записям | **Массовые операции** |

### Откуда берётся итоговое значение

Модуль выбирает источник отдельно для каждого поля. На странице фильтра сначала проверяются **индивидуальные настройки адреса**, затем **подходящие групповые правила**, затем **базовые настройки профиля каталога**. Если модуль не нашёл значения, используется штатное SEO страницы в Битрикс.

В каждом источнике собственное заполненное поле имеет приоритет над соответствующим полем назначенного набора. Если индивидуальная запись задаёт только Description, Title может поступить из группового правила, а H1 — из профиля. При проверке адреса смотрите источник рядом с каждым полем.

## 1. Наборы шаблонов

**Что делает.** Раздел хранит комплекты SEO-полей, общие параметры сайта и словари. Само создание набора ещё не меняет страницы. Чтобы набор начал действовать, назначьте его профилю, групповому правилу или индивидуальной странице.

**Когда использовать.** Когда одну формулировку или схему подстановки нужно использовать на нескольких страницах. Например, для всех страниц, отфильтрованных по бренду.

### Вкладка «Наборы шаблонов»

1. Нажмите **Создать набор** или откройте существующий по названию.
2. Введите понятное **Название набора**, например «Каталог — страницы брендов».
3. Заполните нужные поля. Оставьте незаполненными поля, которые набор не должен задавать.
4. Нажмите **Сохранить набор** и назначьте его нужной записи. Проверьте один или несколько URL, на которых он должен работать.

При редактировании общего набора изменения затронут все связанные записи, в которых это поле берётся из набора. Если задача касается одного адреса, удобнее изменить нужное поле в индивидуальной карточке.

### Вкладка «Параметры сайта»

**Что делает.** Хранит основной адрес сайта и короткие значения, которые можно подставлять в шаблоны. Например, параметр с именем `shop_name` и значением `Pablosky` доступен как `{{ param.shop_name }}`.

**Когда использовать.** Для повторяющихся данных сайта: названия магазина, города или другой стандартной формулировки. Основной адрес нужен для полных ссылок в шаблонах и в предпросмотре.

1. Выберите сайт. Введите его основной адрес с протоколом, например `https://example.ru`, без пути к разделу.
2. Нажмите **Добавить параметр**. Укажите имя латинскими буквами, при необходимости с цифрами и подчёркиванием. Начните имя с буквы. В соседнем поле введите значение.
3. Чтобы убрать параметр, нажмите **Убрать** рядом с ним. Нажмите **Сохранить параметры**.

Если у профиля каталога есть параметр с тем же именем, в контексте этого профиля используется его значение. Перед удалением параметра проверьте шаблоны, которые его используют.

### Вкладка «SEO-словари»

**Что делает.** Словарь сайта хранит редакционные названия и падежные формы разделов и значений фильтра. Например, цвет витрины «Белый» можно подставить как «белого цвета». Запись словаря используется только через соответствующую переменную шаблона. Она не переименовывает раздел или значение в каталоге.

**Когда использовать.** Когда оригинальное название неудобно вставлять в предложение, нужна другая форма слова или витринное название не подходит для метаданных. Общие формы доступны и на индивидуальной странице, если соответствующее поле использует шаблон с контекстом фильтра.

**Одна форма вручную**

1. Выберите **Сайт** и **Инфоблок**. Инфоблок — каталог, из которого берутся разделы и свойства.
2. В поле **Раздел для списка значений** оставьте корень либо выберите раздел, где есть нужное значение. Это меняет список для выбора, а не область действия словаря.
3. Выберите запись, форму и введите текст. Нажмите **Сохранить фразу**.
4. Подставьте её в шаблон и проверьте адрес. Примеры переменных: `{{ section.seo }}`, `{{ section.seo.genitive }}`, `{{ property.color.seo }}`, `{{ property.color.genitive }}`. Вместо `color` укажите код свойства из редактора.

Формы заполняются вручную. Модуль не склоняет слова автоматически. Выбирайте падеж под конкретную фразу и проверяйте результат целиком.

**Несколько форм через «Импорт CSV»**

1. Выберите сайт и его инфоблок. Нажмите **Скачать шаблон CSV**.
2. Заполните файл. Замените примерные ID и RAW на значения из подписей в списке записей словаря. При редактировании в таблице храните RAW как текст, чтобы сохранить нули и буквенные коды.
3. Сохраните файл в **UTF-8**, с разделителем **точка с запятой**. Допускается до **1 МиБ** и **5 000 строк данных**. Заголовки и порядок колонок должны совпадать с шаблоном.
4. Выберите файл и нажмите **Проверить файл**. Просмотрите добавления, замены и количество неизменённых форм. Ошибки показаны с номерами строк файла. Исправьте их и проверьте файл повторно.
5. Нажмите **Применить изменения**. Если за время проверки словарь изменился, выполните проверку ещё раз. Если при первом импорте предложено **Подготовить хранилище для импорта**, запустите подготовку с правами записи либо обратитесь к администратору.

| Колонка | Для строки раздела | Для строки значения фильтра |
|---|---|---|
| `TYPE` | `section` | `property` |
| `ID` | ID раздела | ID свойства |
| `RAW` | Пусто | Исходное значение, включая `0`, если оно указано в списке |
| `SECTION_ID` | Пусто | ID раздела, в котором доступно значение. Пусто для корня каталога |
| `FORM` | Код формы | Код формы |
| `VALUE` | Текст формы | Текст формы |

```csv
TYPE;ID;RAW;SECTION_ID;FORM;VALUE
section;12;;;seo;Обувь для девочек
property;34;0;12;genitive;белого цвета
```

Коды форм: `seo` — основная SEO-форма, `genitive` — родительный, `dative` — дательный, `accusative` — винительный, `instrumental` — творительный, `prepositional` — предложный. Одна строка задаёт одну форму. Не оставляйте `VALUE` пустым и не повторяйте одну форму для той же записи. Если текст содержит точку с запятой, заключите его в двойные кавычки. Внутренние двойные кавычки удвойте.

Импорт добавляет и обновляет перечисленные формы. Остальные формы сохраняются. Файл с ошибками целиком остаётся неприменённым. Весь импорт можно восстановить одной записью через **Историю изменений**, если словарь с того момента не редактировали.

## 2. Правила применения

**Что делает.** Назначает SEO группе страниц фильтра по каталогу, разделу и выбранным свойствам. У каждого правила можно указать набор шаблонов и собственные поля.

**Когда использовать.** Когда одинаковые настройки нужны для нескольких адресов, которые легко описать условием. Например, для страниц с брендом Pablosky в разделе «Обувь для девочек».

1. Нажмите **Добавить правило**. Укажите название, профиль и отметьте **Активно**, если правило должно работать.
2. Выберите разделы. Пустой список означает весь каталог этого профиля. Опция **Включая подразделы** распространяет условие на дочерние разделы.
3. В блоке **Разделы и условия** нажмите **Добавить условие**. Выберите свойство, способ сравнения и значения. Все добавленные условия должны выполняться одновременно.
4. При необходимости отметьте **Разрешать дополнительные фильтры**. Например, правило по бренду сможет сработать и при дополнительно выбранном цвете. При выключенной опции цвет должен быть учтён одним из условий правила.
5. Назначьте **Набор шаблонов**, заполните нужные собственные поля и задайте **Приоритет**. У групповых правил **большее число** применяется раньше. При равном числе первым идёт правило с меньшим ID.
6. Введите **URL для проверки** и нажмите **Проверить без сохранения**. Посмотрите итоговые поля и пересечения. Проверьте хотя бы один подходящий адрес и один адрес, на который правило не должно влиять. Нажмите **Сохранить**.

| Сравнение | Как работает |
|---|---|
| **Точный набор** | У выбранного свойства ровно те значения, которые перечислены в правиле. |
| **Любое из выбранных** | Достаточно совпадения хотя бы одного значения. Например, красный или белый. |
| **Все выбранные** | Должны присутствовать все указанные значения. Дополнительное значение того же свойства допускается. |
| **Не выбрано** | У этого свойства нет выбранного значения или диапазона. |
| **Точный диапазон** | Границы числового свойства должны совпасть с указанными «От» и «До». Это проверка границ фильтра, а не поиск значений внутри интервала. |

Флажок дополнительных фильтров относится к другим свойствам. Для ограничения дополнительных значений внутри одного свойства используйте **Точный набор**.

## 3. Индивидуальные страницы

**Что делает.** Применяет метаданные к одному точному адресу выбранного сайта. Карточка задаёт SEO для существующей страницы каталога или другого адреса. Она не создаёт товарную страницу.

**Когда использовать.** Когда у одного URL должны быть собственные Title, Description или SEO-текст. Например, для посадочной страницы рекламной кампании.

1. Нажмите **Добавить** либо откройте запись по названию. На вкладке **Параметры** укажите **Название**, **Сайт**, **Путь** и состояние **Включён**. Используйте путь с начальным `/` или полный адрес своего сайта. Для индивидуальной карточки нужен точный адрес без масок и UTM-меток.
2. Если для того же адреса есть несколько точных правил, здесь **меньшее число** означает более высокий приоритет. При равенстве первым идёт правило с меньшим ID. Как правило, одного активного правила на адрес достаточно.
3. На вкладке **SEO** задайте только те поля, которые хотите изменить. Если выбрали набор, проверьте и его поля: они также могут переопределить общие настройки.
4. Откройте **Проверка** и нажмите **Проверить несохранённые изменения**. Убедитесь, что изменились нужные поля.
5. **Применить** сохраняет запись и оставляет карточку открытой. **Сохранить и закрыть** возвращает к списку. Вкладка **История** открывает правки этой записи после первого сохранения.

Чтобы временно убрать влияние записи, в поле **Включён** установите **Нет** и сохраните. Чтобы найти нужную карточку, используйте поиск по URL, сайту, активности или дате изменения. В списке можно выбрать сортировку, количество строк на странице и видимые столбцы.

## 4. Профили каталога

**Что делает.** Связывает модуль с конкретным фильтром каталога. Профиль определяет сайт, инфоблок, структуру адресов и базовые SEO-настройки для распознанных страниц фильтра.

**Когда использовать.** При подключении каталога или при изменении его базового набора. Технические настройки профиля обычно заполняет администратор. Для одного адреса или группы адресов используйте соответственно индивидуальную страницу или групповое правило.

| Поле | Что указать |
|---|---|
| **Название**, **Включён** | Понятное имя профиля и состояние активности. |
| **Сайт**, **Каталог** | Сайт и инфоблок, используемые страницами каталога. |
| **Корень каталога** | Базовый путь, например `/catalog/`. |
| **SEF-шаблон** | Схема читаемого адреса фильтра, используемая сайтом. Например, `#SECTION_CODE_PATH#/filter/#SMART_FILTER_PATH#/apply/`. Сверьте с администратором. |
| **Коды типов цен** | Те же коды, что у публичного фильтра. Перечисляются через запятую. Пустое поле означает работу без ценовых типов. |
| **Недоступные товары** | Порядок показа недоступных товаров, совпадающий с настройкой каталога. |
| **Параметры** | Значения, используемые в шаблонах этого профиля. Одноимённые параметры профиля перекрывают параметры сайта. |
| **Набор SEO-шаблонов** и собственные SEO-поля | Базовые метаданные для страниц фильтра, когда более точный источник не дал значения. |

После изменения проверьте несколько реальных адресов с активным фильтром на вкладке **Проверка**. Если адрес перестал распознаваться, проверьте настройки пути и фильтра вместе с администратором. Список профилей можно фильтровать по названию, сайту, активности и дате.

## 5. Страница по фильтру

**Что делает.** Подбирает и проверяет один адрес по выбранным значениям smart-фильтра. Из результата можно открыть карточку индивидуальных метаданных.

**Когда использовать.** Когда известны нужный раздел, цвет или бренд, а готового URL нет под рукой.

1. Выберите **Профиль**. В блоке **Или выбрать раздел и значения фильтра** выберите раздел или корень каталога.
2. Отметьте нужные значения. Для нескольких вариантов в одном списке воспользуйтесь стандартным множественным выбором, например Ctrl + клик в Windows.
3. Нажмите **Проверить выбранную страницу**. Модуль проверит адрес штатным фильтром, покажет результат и заполнит поле **URL для предпросмотра**.
4. Если адрес уже известен, вставьте его в это поле и нажмите **Проверить страницу**.
5. Чтобы переопределить SEO, нажмите **Создать индивидуальные метаданные**. Заполните и сохраните открытую карточку. До сохранения настройки страницы не меняются.

Если сочетание значений не подтверждается, откройте публичный каталог, выставьте фильтр и скопируйте полученный URL для проверки.

## 6. Проверка URL

**Что делает.** Показывает расчёт SEO по сохранённым настройкам для указанного сайта и адреса. Имитирует сниппет, выводит итоговые поля, их источники, предупреждения и данные для подстановки.

**Когда использовать.** После изменения набора, правила или словаря и при разборе неожиданного Title или Description.

1. Выберите **Сайт** и введите **URL для проверки**. Нажмите **Проверить**.
2. Сверьте Title, Description, H1, Robots и Canonical. У отдельных полей доступен переход к источнику.
3. Посмотрите список применённых правил и подставленных значений. Если переменная пуста, убедитесь, что нужное свойство выбрано в фильтре, параметр существует и форма заполнена в словаре этого сайта.
4. При необходимости нажмите **Создать индивидуальную страницу** и сохраните нужные изменения в карточке.

Проверка URL не публикует изменения. Для черновика используйте вкладку **Проверка** в карточке или кнопку **Проверить без сохранения** в правиле. Если поле остаётся на стороне Битрикс, откройте публичную страницу и проверьте фактическое значение там. Поисковик может показать собственный заголовок и описание вместо примера сниппета.

## 7. История изменений

**Что делает.** Показывает время изменения, номер пользователя и изменённые данные. Общий раздел называется **История изменений** в меню и **История** во вкладках модуля.

**Когда использовать.** Чтобы выяснить, кто менял настройки, сравнить версии или вернуть предыдущее состояние.

1. Откройте общий раздел либо кнопку **История** рядом с конкретной записью.
2. Нажмите **Показать изменения** в нужной записи.
3. Если требуется откат, нажмите **Восстановить значения до изменения** и подтвердите. Восстановление тоже записывается в историю.

Восстановление защищено от перезаписи более свежих правок. Если запись уже изменилась, откройте текущую карточку и внесите нужные значения вручную. Для отмены действия новой индивидуальной записи отключите её. Импорт словаря ищите по записи **Импорт SEO-словаря сайта …**.

## 8. Массовые операции

**Что делает.** Позволяет пакетно поменять SEO-поля, их режимы, активность или назначенный набор у существующих **индивидуальных страниц** и **профилей каталога**. Для словарей предусмотрен отдельный импорт во вкладке **SEO-словари**.

**Когда использовать.** Например, чтобы подключить один набор к нескольким страницам или отключить группу старых индивидуальных настроек.

1. Откройте нужный список. Выделите строки и нажмите **Изменить выбранные** либо сначала выполните поиск и нажмите **Изменить все найденные**. Второй вариант охватывает результаты на всех страницах выдачи. Флажок в шапке таблицы отмечает строки только текущей страницы.
2. Для нужных полей установите флажки **Изменить …**, затем задайте режим и значение. Если нужно, отдельно задайте активность или выберите набор. Поля без флажков сохраняют прежние значения.
3. Нажмите **Подготовить изменения**. Откройте отчёт и проверьте количество записей, перечень изменений и ошибки. Подготовка ещё не применяет правки.
4. После проверки автор операции нажимает **Применить … подготовленных изменений**. Статус можно отслеживать в разделе **Массовые операции**. Если операция готовится или выполняется и доступна кнопка **Обработать пакет сейчас**, ею можно запустить очередную обработку.
5. Проверьте итоговые счётчики и строки с ошибками. Если запись успели изменить после подготовки, операция защищает её от перезаписи. Проверьте текущую карточку и подготовьте исправление для этой записи отдельно.

## Справочник SEO-полей и шаблонов

| Поле | Что задаёт | Когда заполнять |
|---|---|---|
| **Title** | Название во вкладке браузера и возможный заголовок в поиске | Когда странице нужен узнаваемый, конкретный заголовок. |
| **Description** | Краткое описание страницы для поисковиков | Когда нужно рассказать, что посетитель найдёт по этому адресу. |
| **H1** | Основной видимый заголовок на странице | Когда стандартный заголовок слишком общий для выбранного фильтра. |
| **Keywords** | Содержимое метатега keywords | Если его заполнение предусмотрено правилами проекта. |
| **Robots** | Инструкция поисковым роботам об индексации и переходе по ссылкам | Когда эту инструкцию нужно явно задать по согласованному SEO-правилу. |
| **Canonical** | Предпочтительный адрес страницы | Когда нужно явно указать основной адрес. В редакторе есть заготовки для текущего URL и раздела каталога. |
| **SEO-текст сверху и снизу** | Текстовые блоки каталога в поддерживающем шаблоне сайта | Для полезного пояснения, которое должно быть видно посетителю. В редакторе есть кнопки абзаца, выделения и списка. |

В карточке у каждого поля есть три режима. **Наследовать** — взять поле из назначенного набора, если оно там есть, либо передать выбор следующему источнику. **Свой текст** — опубликовать введённую формулировку буквально. **Шаблон** — вычислить текст с подстановками. В библиотеке наборов заполненные поля сохраняются как шаблоны. Обычный текст в них выводится как есть, пока в нём нет выражений подстановки.

Чтобы вставить переменную, поставьте курсор в нужное поле в режиме **Шаблон** и нажмите на переменную в блоке **Переменные и форматирование**. Доступность значения зависит от сайта, профиля и текущего фильтра.

| Подстановка | Что получится |
|---|---|
| `{{ section.name }}` | Название текущего раздела. |
| `{{ property.brand }}` | Выбранный бренд или список выбранных брендов. |
| `{{ property.brand.values \| join(", ") }}` | Выбранные значения бренда с указанным разделителем. |
| `{{ param.shop_name }}` | Значение параметра сайта или профиля. |
| `{{ property.color.genitive }}` | Родительная форма значения цвета из словаря. |
| `{{ url }}` | Полный адрес страницы, если задан основной адрес сайта. |
| `{{ count }}` | Количество товаров, если каталог предоставил это значение. При отсутствии данных оно остаётся пустым. |

Пример Title с запасным текстом, если бренд не выбран:

```text
{{ section.name | default("Детская обувь") }}{% if property.brand %} — {{ property.brand }}{% endif %} | {{ param.shop_name | default("Pablosky") }}
```

Здесь `default` подставляет запасное значение, а часть между `if` и `endif` выводится при наличии бренда. `lower`, `upper`, `capitalize` и `trim` помогают привести текст к нужному регистру или убрать лишние пробелы. Проверяйте формулировку на адресах с разными значениями, в том числе с пустыми подстановками.

## Права доступа

Настройки самого модуля в Битрикс содержат вкладку **Права доступа**. Администратор использует её, чтобы выдать группе право просмотра или редактирования. Контент-менеджеру для ежедневной работы достаточно разделов меню **SEO по шаблонам**. Для публикации, массовых операций, восстановления и импорта требуется право записи.

## Рабочий пример. Общий Title и своё описание для одной страницы

1. В **Наборы шаблонов** создайте набор «Белая обувь» и задайте Title «Белая детская обувь».
2. В **Правила применения** добавьте правило для нужного профиля с условием **Цвет → Точный набор → Белый**. Назначьте набор и проверьте пример URL. Если правило должно работать и при выбранном размере, включите **Разрешать дополнительные фильтры**.
3. В **Страница по фильтру** выберите нужный раздел и белый цвет, проверьте адрес и нажмите **Создать индивидуальные метаданные**.
4. В индивидуальной карточке оставьте Title в режиме **Наследовать** и поле **Набор SEO-шаблонов** в состоянии **Без набора**. Для Description выберите **Свой текст** и введите описание нужной страницы. Проверьте черновик и сохраните его.
5. В **Проверка URL** убедитесь, что Title поступает из группового правила, а Description — из индивидуальной страницы.
